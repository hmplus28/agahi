# مشخصات بازطراحی رابط RTL سامانهٔ آگهی

## جهت‌گیری محصول

رابط کاربری جدید باید سریع، آشنا و مناسب تصمیم‌گیری در بازار آگهی باشد. از الگوهای کاربردی مشاهده‌شده در پلتفرم‌های آگهی—انتخاب شهر، جست‌وجوی برجسته، دسته‌بندی قابل‌اسکن، فهرست قابل فیلتر و کارت‌های اطلاعات‌محور—استفاده می‌شود، اما هویت بصری و کپی‌رایت آن کاملاً مستقل است. [1](https://divar.ir/s/tehran/list/jobs-web-designer) [2](https://www.webpouya.com/blog/analysis-of-the-design-of-the-divar-site)

## زبان بصری

| مؤلفه | تصمیم |
|---|---|
| رنگ برند | `#0F766E` سبز-آبی برای CTA و وضعیت‌های اصلی؛ کهربایی برای «ویژه» و قرمز-نارنجی محدود برای «فوری». |
| پس‌زمینه | خاکستری بسیار روشن با سطح‌های سفید؛ مرزهای ظریف برای تشخیص کارت‌ها بدون سنگین‌شدن صفحه. |
| تایپوگرافی | فونت سیستم فارسی/Arabic fallback؛ مقیاس ۱۲، ۱۳، ۱۵، ۱۷، ۲۰ و ۲۸ پیکسل با line-height خوانا. |
| آیکون | SVG خطی کوچک و inline؛ بدون کتابخانه یا فایل خارجی. |
| گوشه و سایه | radius بین ۱۰ تا ۱۶ پیکسل؛ سایه تنها در hover و sticky cardها. |
| RTL | `dir="rtl"` در ریشه؛ nav، فرم‌ها، breadcrumb، فیلتر و اطلاعات متنی راست‌چین؛ شماره‌ها و قیمت با `dir="ltr"` در محدودهٔ لازم. |

## معماری صفحات

| صفحه | ناحیه‌های کلیدی |
|---|---|
| خانه | هدر فشرده، نوار جست‌وجوی کاربردی، دسته‌های شبکه‌ای با آیکون، آگهی‌های منتخب، تازه‌ترین آگهی‌ها، CTA ثبت آگهی. |
| جست‌وجو | نوار جست‌وجوی ثابت در بالای محتوا، فیلتر کنار صفحه در دسکتاپ و panel قابل‌گسترش در موبایل، تعداد نتیجه و کارت‌های چهارستونه/تک‌ستونه. |
| جزئیات آگهی | breadcrumb، گالری، پنل sticky مشخصات و CTA تماس، ویژگی‌های کلیدی، توضیحات و آگهی‌های مرتبط. |
| دسته | عنوان و توضیح SEO، زیر‌دسته‌ها به‌شکل chip، شبکهٔ آگهی. |
| حساب کاربر | همان layout پایه با کارت‌های کاربردی و بدون wrapper متفاوت. |

## معیار پذیرش

- صفحهٔ اصلی در موبایل و دسکتاپ کاملاً RTL و خوانا باشد.
- مسیر جست‌وجو، فیلتر، مشاهدهٔ کارت و ثبت آگهی در نگاه اول قابل‌تشخیص باشد.
- هیچ asset خارجی یا JavaScript اجباری اضافه نشود.
- تصاویر کارت lazy-load بمانند و ساختار SSR/SEO حفظ شود.
- focus کیبورد، کنتراست، label فرم‌ها و اندازهٔ touch targetها رعایت شوند.
