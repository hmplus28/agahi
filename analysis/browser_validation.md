# اعتبارسنجی مرورگری نسخهٔ PHP

تاریخ: ۲۰ اوت ۲۰۲۶

## یافته‌های تأییدشده

- صفحهٔ اصلی و صفحهٔ جزئیات آگهی با HTTP 200 و محتوای اصلی فارسی در پاسخ سمت‌سرور رندر شدند.
- صفحهٔ اصلی شامل H1، فرم جست‌وجو، دسته‌بندی، کارت آگهی و لینک‌های واقعی HTML است.
- جزئیات آگهی شامل Breadcrumb، H1، توضیحات، اطلاعات تماس، فرم گزارش تخلف و دادهٔ ساخت‌یافتهٔ JSON-LD در head است.
- عنوان صفحهٔ آگهی، canonical و robots policy در پاسخ دیده شد.

## اصلاح شناسایی‌شده

در محیط proxy موقت، مقدار محلی `APP_URL=http://...` باعث تولید URL مطلق HTTP برای assetها شد و مرورگر HTTPS stylesheet را به‌دلیل mixed content دریافت نکرد. این مسئله با استفاده از مسیر نسبی برای stylesheet در قالب پایه و تعیین `APP_URL=https://دامنه` در production اصلاح می‌شود. نام «Laravel» نیز فقط از `.env` محلی development می‌آید؛ `.env.example` نام فارسی سامانه را مشخص کرده است.
