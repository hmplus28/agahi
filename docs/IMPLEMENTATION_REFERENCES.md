# منابع پیاده‌سازی SEO و عملکرد

تصمیم‌های مربوط به canonical، robots meta، تصاویر LCP و static files در این پروژه بر مبنای منابع رسمی زیر اتخاذ شده‌اند.

| موضوع | منبع |
|---|---|
| Canonical برای URLهای دارای فیلتر و مرتب‌سازی | [Google Search Central: Canonicalization](https://developers.google.com/search/docs/crawling-indexing/canonicalization) |
| کنترل page-level indexing با robots meta | [Google Search Central: Robots meta tags](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag) |
| عدم lazy-load تصویر LCP و استفاده محدود از `fetchpriority="high"` | [web.dev: Optimize Largest Contentful Paint](https://web.dev/articles/optimize-lcp) |
| اجرای `collectstatic` و سرویس‌دهی static در production | [Django 5.2: Deploying static files](https://docs.djangoproject.com/en/5.2/howto/static-files/deployment/) |
