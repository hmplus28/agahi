# یادداشت بررسی صفحات مرجع

تاریخ بررسی: ۲۰ اوت ۲۰۲۶

## صفحهٔ اصلی مرجع (`/ui-home.htm`)

صفحهٔ موجود یک پوستهٔ بسیار ساده و قدیمی RTL دارد. عناصر قابل انتقال آن شامل انتخاب شهر، شمارهٔ تماس، لینک‌های خدمات/درباره‌ما/تماس، ورودی به پنل کاربر، ثبت آگهی، جست‌وجوی عمومی با دسته‌بندی و بازهٔ قیمت، و کارت‌های آگهی است. کارت‌ها باید حداقل تصویر، عنوان، قیمت یا عبارت «توافقی»، شهر و تاریخ داشته باشند. این صفحه فاقد کیفیت بصری، معنای HTML و الگوی کارایی موردنیاز نسخهٔ جدید است؛ بنابراین صرفاً منبع منطق کسب‌وکار و نه منبع UI است.

## صفحهٔ مدیریت آگهی مرجع (`/admin-ads.htm`)

پنل موجود ماژول‌های آگهی، پرداخت، تعرفه، دسته‌بندی، تیکت، لغات غیرمجاز، گزارش و تمدید را نشان می‌دهد. صفحهٔ مدیریت آگهی دارای تب‌های تعدادمحور برای همه، نیاز به تأیید، نیاز به تمدید، نیاز به مجوز، فعال، غیرفعال و حذف است. هر ردیف باید تاریخ، عنوان، کد، بازدید، نویسنده، معرف، خدمات، وضعیت و عملیات داشته باشد. عملیات موردنیاز شامل انتشار/تأیید، ویرایش و بازبینی مجوز است. جست‌وجوی مدیریت باید چندفیلدی باشد و برای کد و موبایل از جست‌وجوی دقیق یا پیشوندی استفاده شود. «فاقد بازدید» یک فیلتر محاسباتی است، نه وضعیت مستقل. 

## تصمیم‌های انتقالی

نسخهٔ PHP نباید ظاهر یا ساختار صفحه‌های مرجع را کپی کند. صفحه‌های عمومی با HTML سمت‌سرور، RTL، طراحی mobile-first، CSS کم‌حجم و JavaScript حداقلی پیاده‌سازی می‌شوند. منطق وضعیت و عملیات پنل مدیر به یک ماشین وضعیت و لایهٔ سرویس منتقل می‌شود تا کنترل دسترسی و ثبت رویدادها در سرور enforce شود.
